# 0.2.1 界面精简

根据用户反馈移除口号、欢迎描述、Smart 标签、步骤编号、页脚文案、重复订阅状态及装饰性符号。

设置页直接展示订阅、连接和折叠的网站规则。弹窗只展示状态、线路、连接按钮、延迟检测和订阅更新。未导入时显示添加订阅入口；错误、冲突及必要的保存反馈继续显示。

正文、输入框、线路和主按钮 16px，表单标签与次要操作 15px，更新时间等辅助文字最低 14px；标题 21–26px。文字对比度提高，禁用状态不再通过降低整块透明度表现。弹窗宽 360px，内容高度约 402px，主要按钮高 48px。

已更新 `dist/extension` 与 `releases/qingkong-0.2.1.crx`，继续复用现有签名密钥。通过构建及必要的隔离 Chrome UI 检查：订阅导入、地址显隐、设置页选线/连接、规则展开/保存、窄屏布局、弹窗图标及断开。仅用合成订阅检查，没有修改服务器或用户日常 Chrome。

预览：`docs/screenshots/settings-v3.png`、`popup-v3.png`、`settings-v3-mobile.png`。

已安装目录版的用户，在 `chrome://extensions` 点击晴空的重新加载，再关闭重开设置页或弹窗即可。订阅和规则保留。

这次更新只涉及 UI/UX。此前报告的代理认证弹窗问题仍待单独排查，不能将本轮界面检查视为认证问题已修复。
