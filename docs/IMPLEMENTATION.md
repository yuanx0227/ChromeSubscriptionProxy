## 已实现

| 模块 | 行为 |
|---|---|
| `extension/src/model.js` | HTTPS 订阅验证、8 MiB 限制、安全 YAML 解析、兼容节点筛选、端点唯一性、域名规范化与冲突拒绝 |
| `extension/src/pac.js` | Smart IPv4/IPv6、最长自定义域名优先、前缀编码国内域名、无 DIRECT 兜底、移除节点阻断 |
| `extension/src/background.js` | MV3 生命周期、串行配置更新、持久缓存、每日 alarm、真实代理控制权、代理专属认证、手动延迟 |
| `extension/src/ui.js` | 弹窗和设置交互、导入结果、配置/连通性独立状态、错误脱敏 |
| `server/bridge.py` | 只读面板事务、有效身份筛选、原订阅读取、持久端口分配、UUID 变更轮换凭据、按用户补充订阅、Xray 配置编译 |
| `server/service.py` | 30 秒同步、仅本机 HTTP 适配、降权桥接子进程、配置预检查、证书同步、专属 nftables 规则、失败停止桥接 |

国内规则快照包含 110,640 个域名、6,207 段合并 IPv4、3,415 段合并 IPv6。空自定义规则的 PAC 约 977,327 字节，具体大小随节点/订阅域名变化；应用上限 1 MiB。超限时拒绝新规则，不默默删减。最多 2,000 项/类的自定义规则数量限制并不保证全部都能装入脚本，实际还受字节上限限制。

## 已知边界与维护

- 服务器初版把一个同步周期视为整体事务。任一有效订阅读取失败时暂停整个浏览器桥接，以免继续分发无法确认的身份映射；原 Xray 客户端不受此 supervisor 控制。
- 本地代理配置采用 Chrome 的常规代理控制，不是所有浏览器协议或操作系统流量的防泄漏工具。
- 因代理身份与端点严格绑定，端口注册表不可随意重建；历史端口不自动回收。初始 100 个槽位耗尽后需显式扩大范围并核对防火墙。
- 默认规则可能随时间过期；更新需开发者执行公开数据更新脚本再构建，不运行订阅内的脚本/PAC。
- 原设计中的“尚未实现”叙述为设计阶段记录，当前以本文件和 README 为准。未启用新的订阅处理服务或改动现有 Caddy。
- 旧研究目录中那份可能含凭据的 Playwright 快照，之前的删除已被自动审批拒绝。它未复制到本项目，本轮未尝试绕过该限制。
