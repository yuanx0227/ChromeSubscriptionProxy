# 浏览器流量通过原用户节点认证和计量

服务器供多位使用者使用，用户明确要求每人的浏览器流量累计到现有3x-ui个人记录并沿用原额度和到期控制。用户在Q18确认：保留纯Chrome扩展，服务器新增HTTPS代理桥接，按独立用户身份转发到其原VLESS/REALITY节点；原CLASH地址通过本机适配服务补充该用户的浏览器节点。

不采用全局共享凭据的inline provider。也不只凭同名HTTP计数器认定限制已正确执行：原面板的停用链路针对原客户端身份，桥接必须真正通过该身份转发，才能复用其认证和计量。

Q19限定首版优先兼容当前VLESS/TCP/REALITY。Q20要求身份、订阅和UUID变化自动同步，目标一分钟内，可接受必要的浏览器连接短暂重连。此决策确认设计，不是服务器部署授权。
