# 每个原节点身份使用独立稳定代理端口

Chromium会按代理地址缓存有效认证，用户名是缓存值；同一host:port下仅改变onAuthRequired返回值不能保证切换身份。用户在Q21确认，为每个原节点身份分配独立、稳定的HTTPS端口，同一桥接进程按入口固定映射到原节点。

当前6个身份拟用18443–18448。相比单端口方案，这增加监听端口和相应端口规则，但无需引入新的DNS/TLS别名，也不依赖清cookies或全部连接。每条订阅只获得自己的端口和凭据，端口不静默移交给另一身份。

此决策替代Q18中的单公网端口实现细节，保留纯扩展、原订阅URL、原用户计量与自动同步的整体架构。源码证据见proxy-auth-cache.md；实际切换与计量仍需实施后的必要验收。
