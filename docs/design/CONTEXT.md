# Chrome 订阅代理

通过订阅管理浏览器代理节点和访问分流，用户无需注册或登录本插件的账号。

## Language

**订阅地址**：提供一组代理节点信息的地址。地址本身可能含访问凭据；“无需登录插件”不代表订阅公开或节点无需认证。
_Avoid_: 登录账号、节点地址

**订阅格式**：节点信息的表达形式。SUB 与 CLASH 是本需求中待选择的两类输入，具体方言与字段以实际内容为准。
_Avoid_: 代理协议

**代理节点**：一个可用于转发流量的连接目标，包含建立连接所需的地址、协议及认证信息。
_Avoid_: 订阅、订阅地址

**原节点**：现有面板为某位用户提供的节点身份和连接目标，其认证及流量归属继续由现有面板管理。
_Avoid_: 浏览器节点

**浏览器节点**：某个原节点面向Chrome的兼容入口。它使用独立的浏览器代理凭据，但转发后的流量仍归属于对应原节点的用户身份。
_Avoid_: 共用代理账号、独立计费账号

**节点映射**：一个原节点与其浏览器节点的对应关系，保证订阅归属、转发目标和流量归属一致。
_Avoid_: 全部用户共用同一节点

**用户身份**：服务器用来区分各位使用者的认证身份，对应现有面板中的个人客户端记录。多位用户可以共享一个服务器入口，但身份与流量归属各自独立。
_Avoid_: 端口、服务器IP

**用户流量**：归属于某个用户身份的上传和下载用量。浏览器插件与该用户其它客户端的用量需累计到现有面板的同一归属，沿用原额度与到期设置。
_Avoid_: 所有用户共享的节点总流量、插件本地计数

**代理协议**：客户端与代理节点建立连接和传输流量所遵循的规则。
_Avoid_: 订阅格式

**分流规则**：决定一类浏览器请求采用直连还是代理的条件。
_Avoid_: 节点选择

**Smart 分流**：本产品唯一的首版分流模式，按本地网络、自定义域名、默认国内域名及中国大陆地址范围决定直连，其余目标使用代理。
_Avoid_: 自动选线、自动选择最快节点

**代理失败**：按分流规则应经过代理的请求未能完成连接。该状态保留原来的代理意图，不自动变为直连。
_Avoid_: 自动断开、自动直连

**有效订阅缓存**：上次成功取得且能用于本产品的订阅内容。刷新失败不自动使这份缓存失效。
_Avoid_: 当前网络连接状态

**直连**：浏览器请求不经过本产品选择的代理节点，使用本地网络访问目标。
_Avoid_: 全局关闭

**插件登录**：用户为了使用插件而进行的账号注册或登录步骤。本需求明确省略这一用户流程。
_Avoid_: 节点认证、订阅访问凭据
