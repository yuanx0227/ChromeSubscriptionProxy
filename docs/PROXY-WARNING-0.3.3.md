# 0.3.3 代理错误提示修复

用户反馈代理可用且延迟检测成功，弹窗仍显示“Chrome 报告代理错误”。源码确认旧处理忽略 onProxyError 的 fatal 字段，对所有事件保存同一常驻警告；事件又和探测使用同一队列，探测过程中收到的事件可能在成功后重新写回。成功检测也没有恢复警告徽标。

现在仅处理属于本扩展当前代理配置的 fatal=true 事件。普通非致命事件不作为整体代理失败提示；致命事件使旧延迟结果失效。记录事件进入队列前的时间，成功探测后忽略早于该成功结果的排队事件，并清除提示、恢复 ON 徽标。旧版本没有分类信息的历史提示在加载时清理。

仅凭截图无法确定该次原始 Chrome 事件的具体网络原因；本次修复的是已确认的提示和队列处理缺陷，不据此认定所有目标都可访问。检测失败依然显示失败，新的致命事件仍保留警告。此前独立的认证弹窗问题未在此轮排查。

必要检查：`node checks/proxy-warning.mjs` 使用后台代码和模拟 Chrome 事件验证旧缓存、非致命/致命事件、探测期间排队事件、恢复徽标、失败探测及断开状态，均通过。构建与 CRX 打包成功，版本 0.3.3。未修改服务器或用户浏览器代理配置。

更新：在 chrome://extensions 重新加载目录版晴空，关闭重开弹窗；有需要时点击“测延迟”。
