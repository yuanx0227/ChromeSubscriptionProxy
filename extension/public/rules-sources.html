规则来源

Shadowrocket-ADBlock-Rules-Forever，作者 Moshel 和 Johnshall。

采用 release 分支的 sr_cnip.conf，仅将 Rule 部分转换为有序 JSON；不包含广告过滤，不导入 General、DNS、URL Rewrite 或 MITM。

原规则及转换后的规则列表按 CC BY-SA 4.0 提供。转换修改：域名规范化，CIDR 转为数值区间/前缀，保留顺序。该许可适用于规则数据，不扩展到本项目独立编写的程序代码。

中国大陆 IPv4/IPv6 网段来自 gaoyifan/china-operator-ip，作者 Yifan Gao，MIT 许可；其数据独立提供给 GEOIP,CN 判定。

来源网址、抓取时间和上游构建时间包含在每份 JSON 的 metadata 中。每日更新不代表每条规则每日经过实测。
